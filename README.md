## 👋 Hey, I'm Vignesh

For three years I've been writing software that real people depend on at work. It started with **React Native** apps for field technicians who often had no signal 📱. Today I'm a full-stack developer at **Intergy Consulting** 🇦🇺, working on a live care-sector platform that matches support workers to clients for **50+ organizations** and **2,000+ users**.

I like owning things end to end: talk through the requirement, write the code, test it, ship it — and stick around to fix whatever breaks in production 🔧.

## 🏆 Things I'm proud of

<details open>
<summary><b>🧯 Took over a live production codebase after a one-month handover</b></summary>
<br/>
Triaged and fixed <b>150+ incidents</b> by priority, shipping hotfixes through GitHub Actions while the platform stayed live.
<br/><br/>
</details>

<details open>
<summary><b>🗄️ Migrated 14,000 records into production — zero data loss</b></summary>
<br/>
Wrote a dry-run comparison script and five validation stages so duplicates never got through. The actual run was uneventful, which is exactly the goal.
<br/><br/>
</details>

<details open>
<summary><b>🔓 Removed the platform's dependency on Salesforce</b></summary>
<br/>
Redesigned the core validation logic and APIs from scratch, so live operations now run fully on our own Django + PostgreSQL stack.
<br/><br/>
</details>

<details open>
<summary><b>📶 Made apps work where the network doesn't</b></summary>
<br/>
Built an offline-first sync system with SQLite, AsyncStorage and retry queues with backoff — sync success went from <b>~30% to ~80%</b>.
<br/><br/>
</details>

<details open>
<summary><b>⚡ Turned a slow workflow into a fast one</b></summary>
<br/>
Tuned PostgreSQL queries and API logic so a long-loading service-creation flow now finishes in <b>seconds</b>.
<br/><br/>
</details>
